### ⚡ Key Capabilities
- **Autonomous GitHub Execution**: Auto-generates repositories, writes branches, and commits pull requests via Octokit REST APIs.
- **State-Machine Thinking UI**: Interactive mascot animation overlay inside the prompt container for smooth, zero-layout-shift processing.
- **Real-Time Web Grounding**: Live search context injection via Tavily to prevent parametric hallucination.
- **Security-First Session Store**: Multi-provider authentication (Google OAuth + Email/Password) with AES-256-GCM encrypted OAuth token persistence.

---

### 🛠️ Tech Stack
- **Framework**: Next.js (App Router) & TypeScript
- **Kernel**: EEK v3.0 Autonomous Agent Engine
- **Tooling**: Octokit REST SDK, Tavily Search API
- **Auth & Crypto**: AES-256-GCM, Argon2/Bcrypt, JWT HTTP-Only Cookies
